# Level İçerik Notları

Yayın öncesinde tüm kelime ve anlamlar doğrulanmalıdır.

## Kontrol Gereksinimleri

- TDK uyumu
- Türkçe karakter desteği
- Uygunsuz kelime filtresi
- Argo ve hassas kelime kontrolü
- Aynı kelime tekrar sıklığı analizi

## Veri Yaklaşımı

Level içerikleri JSON tabanlı tutulur. Aynı veri Unity veya React Native tarafına taşınabilir.
