# Söz Ustası Vault

Bu vault, Söz Ustası'nın ürün, tasarım, içerik ve teknik kararlarını tek yerde tutmak için oluşturuldu.

## Klasörler

- `01-Product`: ürün kimliği, hedef kitle, MVP kapsamı
- `02-Design-System`: renk, tipografi, ekran sistemi, animasyon dili
- `03-Screens`: ekran bazlı wireframe ve davranış notları
- `04-Game-Design`: oyun döngüsü, ekonomi, retention, level mantığı
- `05-Content`: kelime verisi, anlam doğrulama, uygunsuz kelime filtresi
- `06-Tech`: mimari, veri modelleri, component listesi, state yönetimi, audit script
- `07-Production`: kalite kontrol ve yayın öncesi checklist
