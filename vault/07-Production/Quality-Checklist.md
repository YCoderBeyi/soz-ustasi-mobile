# Production Kalite Checklist

## UI

- [ ] Tüm yazılar küçük ekranda okunuyor.
- [ ] Harf halkası tek elle rahat seçiliyor.
- [ ] Kelime kutuları arka plandan ayrışıyor.
- [ ] Anlam kartı akışı yavaşlatmıyor.
- [ ] Safe area destekleniyor.

## Oyun Hissi

- [ ] Doğru kelime tatmin edici.
- [ ] Yanlış kelime rahatsız etmiyor.
- [ ] Mühür açılışı özel hissettiriyor.
- [ ] Gizli kelime ödül gibi hissettiriyor.
- [ ] Level geçişleri hızlı.

## Ekonomi

- [ ] İlk 10 level ipucusuz geçilebilir.
- [ ] Reklam opsiyonel hissettiriyor.
- [ ] Coin satın alma zorunlu değil.

## İçerik

- [ ] Kelime anlamları kısa ve doğru.
- [ ] Türkçe karakterler destekleniyor.
- [ ] Uygunsuz kelime filtresi var.
